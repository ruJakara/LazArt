# LazArt Robot Workshop

Основной проект — учебная игра «Маленькая мастерская».

## Запуск

Откройте папку `robot-workshop` и дважды нажмите `run_game.bat`.
Нужны Windows, Python 3.10+ и браузер. Дополнительные Python-пакеты не нужны.

[Инструкция по игре и режиму PYTHON](robot-workshop/README.md).

## Состав репозитория

- `robot-workshop/` — игра, движок, интерфейс, учебный код и тесты.
- `botfinder/` — сохранённый проект-донор. Его старые инструкции относятся к прежнему развёртыванию; для игры он не нужен.

## Проверка игры

Из папки `robot-workshop`:

```text
python -m unittest discover -s tests -q
```
